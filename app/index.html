Printer

The printer's own web interface, embedded. Use it for full control while SliceDeck handles slicing.

Nothing is embedded here yet. Set Web UI URL on the active printer in Settings — the address of its Fluidd or Mainsail page — and come back. That address is opened by this browser, not by the portal's server, so it has to be reachable from the device you are using right now; a URL that only works from inside the container will leave this section empty. A deployment can also seed it with PRINTER_UI_URL for the environment printer.

This portal is served over HTTPS and the active printer's Web UI URL is plain HTTP, so the browser blocks the frame as mixed content. Open the printer UI with the link below instead, or serve it over HTTPS (its own proxy host is enough) to embed it here. Change the address per printer in Settings; PRINTER_UI_URL is only the environment fallback.
